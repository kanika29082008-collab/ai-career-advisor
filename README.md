# AI Career Advisor 🎓🤖

An AI-powered tool that parses resumes, extracts skills, and matches them against job descriptions to provide personalized career guidance.

## ✨ Features
- 📄 **Resume Parsing**: Extracts text from PDF resumes using `pdfplumber`.
- 🧠 **Skill Extraction**: Detects both technical (Python, SQL, ML, etc.) and soft skills (communication, teamwork).
- 📊 **Structured Profile**: Outputs resume data in JSON format for easy integration.
- 🎯 **Job Match Analysis**: Compares resume skills against job descriptions, highlights gaps, and calculates a fit score.
- 🚀 **Career Guidance**: Suggests skills to learn and paths to strengthen your profile.
